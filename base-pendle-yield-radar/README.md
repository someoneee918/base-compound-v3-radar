# Base Pendle Finance PT/YT Yield Stripping & Fixed-Rate APY Radar

Quantitative analytics engine and edge dashboard modeling Principal Token (PT) fixed APY lock schedules, Yield Token (YT) leverage carry, and logit AMM pull-to-par convergence on Base.

## Key Features
- **Principal Token Fixed APY:** Calculates guaranteed pull-to-par yields (e.g. 28.6% fixed APY on 90-day PT priced at 0.940).
- **Yield Token Leveraged Carry:** Computes 16.67x leverage return on variable yield surges with explicit breakeven APR hurdles.
- **Logit AMM Pull-to-Par:** Models non-linear discount erosion as expiration approaches with minimal impermanent loss.
